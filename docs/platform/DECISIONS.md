# Платформа для художников: решения (Q&A, круги 1–5)

Статус: обсуждение. Кода платформы ещё нет. Артоки (Telegram Mini App + бот на Supabase) остаются как есть
и со временем станут модулем платформы.

## Продукт
Сайт-сервис для художников: страница художника (конструктор блоков, как itch.io), интерактивная заявка на рисунок,
общая галерея, портфолио, заказы, бонусы (модуль Артоки), конкурсы, закрытая вечеринка, оплата через платформу,
проверка возраста и личности.

## Аудитория и юрисдикция
- Россия сейчас, международная версия позже (закладываем мультивалютность и языки в архитектуру).
- Персональные данные россиян хранятся на серверах в РФ (152-ФЗ). Артоки сейчас на Supabase (Франкфурт):
  при переносе в платформу базу придётся перенести на сервер в РФ.

## Контент и возраст
- В РФ-версии: эротика без явных сцен, с проверкой возраста. Явный 18+ откладывается в отдельный сервис за пределами РФ
  (российские платёжные сервисы не обслуживают контент для взрослых, ст. 242 УК РФ).
- Не обсуждается: сексуальный контент с участием несовершеннолетних (включая нарисованных персонажей, выглядящих детьми),
  контент без согласия, изображение реальных людей.
- Модерация: премодерация всего 18+ вручную и жалобы.
- Проверка возраста нужна для: просмотра 18+, выплат (личность), закрытой вечеринки и сообщества, защиты от мошенников и кражи артов.
- Способ: внешний сервис (VK ID / Госуслуги / провайдер верификации). Паспорта и лица у себя не храним, получаем только результат.
- Общая галерея: 18+ работы по умолчанию скрыты, включаются пользователем после проверки возраста.

## Художники и подростки
- Выплаты: самозанятые (НПД) и несовершеннолетние (14–17).
- Подростки только в изолированном режиме: без 18+ (ни видеть, ни создавать), без закрытых мероприятий, заказы только 0+,
  чат под модерацией с копией родителю, согласие родителя, выплаты законному представителю.
- Рекомендация: в первой версии подростки только портфолио и галерея, заказы и деньги для них отдельной фазой после юриста.

## Деньги
- Платформа держит деньги и выплачивает художнику; оплата по этапам заказа (часть выплачивается после принятия каждого этапа).
- Есть ИП (оператор персональных данных и получатель платежей).
- Доход после теста: комиссия с заказа (с художника) и платная подписка для художников. Цифры не выбраны. Тест бесплатный.

## Аккаунты
- Вход: VK ID, Яндекс ID / Госуслуги, почта с кодом / сервис аутентификации. Telegram не выбран (нужна связка с аккаунтами Артоки).

## Заявка на рисунок
- Конструктор формы + калькулятор цены.
- Интерактивный прайс-лист: художник выбирает, как завести его: картинка с кликабельными зонами, привязанными к позициям,
  или структурированная таблица, из которой сайт рисует интерактив.
- Согласие условий и договор (сроки, число правок, права на работу).
- Очередь и слоты переносятся из Артоки.

## Страницы художников
- Конструктор блоков с перетаскиванием.

## Дизайн
- Строгий, но хаотичный; круглый шрифт, «неоконченный, как скетч». Тёмная и светлая темы.
- Артоки внутри сайта одеваем в новый дизайн в момент переноса модуля. До этого Mini App остаётся как есть.

## Технологии и сервер
- TypeScript: Next.js + PostgreSQL, файлы в S3-совместимом хранилище в РФ, Docker на одном VPS в РФ.
- Сервер куплен: 4 ядра, 4 ГБ RAM, 120 ГБ диска. Бюджет около 1000 ₽/мес.
- Команда: один человек вместе с Claude.

## Инфраструктура и сроки (круг 6)
- VPS в России, Ubuntu/Debian, уже работает. Доступы в чат не передаются, деплой запускает владелец командой.
- Масштаб первых 3 месяцев: до 50 художников и несколько сотен клиентов. Облачное хранилище добавим позже.
- Желаемый срок первой версии: 2–3 недели.
- Название платформы есть (не записано), домена нет. Для страниц художников нужен поддомен вида name.домен.ru.

## Уточнение по деньгам
Платформа не должна держать чужие деньги на своём счёте. Деньги по сделке держит платёжный провайдер
(безопасная сделка / мультирасчёты), платформа управляет выплатами. Условия провайдеров нужно проверить у них напрямую.

## Открыто
Название и домен, платёжный провайдер, провайдер верификации, размер комиссии и цена подписки, шрифт,
конкурсы и вечеринка (формат), консультация юриста по интернет-праву и персональным данным.
